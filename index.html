How to add to Apple Podcasts
  1. Copy the Feed URL above.
  2. Open the Apple Podcasts app.
  3. Tap Library at the bottom.
  4. Tap the Edit or Three Dots (...) menu.
  5. Select Add a Show by URL....
  6. Paste the URL and tap Follow.
How to Install as an App
  1. iOS (iPhone): Tap Share in Safari → Add to Home Screen.
  2. IMPORTANT: If asked, ensure "Web App" mode is OFF (or "Open in Browser" is ON) to enable lock-screen playback.
  3. Android: Tap Menu (3 dots) → Add to Home screen.
